02

Data flow

Four distinct request paths through the application. Every flow crosses the same layer boundary — Swing → Service → DAO → Hibernate → PostgreSQL — but touches different tables and carries different payloads.

A
Login.java → sessionManager

User submits username + password. Login.java calls sessionManager.authenticate() which hashes the input with BCrypt and compares against the stored hash via UserDAO.findByUsername(). On success, the user object is held in a static SessionManager.currentUser reference — no JWT, no cookie, all in-memory for the desktop session lifetime.

Sign-up follows the same path but also creates the user row. Password strength is validated client-side via MethodUtil.checkPasswordStrength().

B
WarehousePanel → WarehouseService

All inventory CRUD goes through WarehouseService, the largest service class. addProduct() creates both a ProductEntity and an InventoryEntity in a single transaction. stockIn() / stockOut() update inventory quantities and log to purchase_orders / sales_orders respectively. The panel re-fetches the full table after every mutation via getAllProducts().

TableBadgeCellRenderer decorates the quantity column with colored badges at render time — no separate status column in the DB.

C
orderPanel → orderService

Multi-item cart lives in orderPanel (a JDialog). On confirm, orderService.checkout() validates every line item's quantity against inventory.quantity, then creates an InvoiceEntity + InvoiceDetailEntity rows, deducts stock via InventoryDAO.updateQuantity(), and records each sale in sales_orders. The whole operation is wrapped in a single Hibernate transaction — if any item fails stock validation, everything rolls back.

Invoice PDF export uses iTextPDF 5.5 with a bundled Vietnamese font for Unicode support.

D
AnalyticsPanel → WarehouseService

AnalyticsPanel queries aggregated data through WarehouseService.getAnalytics(), which calls three DAOs: PurchaseOrderDAO.getTotalByCategory() (cost), SalesOrderDAO.getTotalByCategory() (revenue), and InventoryDAO.getStockValue(). Results feed into the custom swing-chart library for pie charts (income/cost/profit by category) and line charts (financial trends over time). Date-range filtering is applied at the DAO level via Hibernate criteria queries.

04

Features

Eight modules accessible from the animated sidebar menu. Every panel is lazy-loaded and refreshable.

📊

Dashboard

Overview cards for profit, stock value, and expenses. Recent stock activity feed. Quick-glance financial health.

📦

Inventory

Full CRUD for products with search, sort, and stock IN/OUT operations. Table badge renderers for stock status.

📈

Analytics

Pie charts (income/cost/profit by category) and line charts (financial trends). Date-range filtering. Custom swing-chart library.

🧾

Invoicing

Multi-item cart with stock validation. Auto-creates invoices on checkout. PDF export with Vietnamese font support (iTextPDF).

🛒

Cart & Checkout

Shopping cart with stock quantity validation. Auto-generates invoice + sales order + inventory deduction on confirm.

🎨

Themes

Four FlatLaf themes: Material You Light/Dark + macOS Light/Dark. Accent color picker. Light/dark toggle in the menu footer.

📝

Log Viewer

Real-time application log with ring buffer. Filter by INFO / WARNING / ERROR / DEBUG. Integrated into the menu system.

⚙

Configuration

Edit database connection and app settings from within the UI. Account management (profile, password, delete). BCrypt auth.
